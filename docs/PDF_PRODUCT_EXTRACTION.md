## 1. What the PDF actually contains

The PDF is an **ingredient / raw-material catalogue** for cosmetic manufacturers. Its tagline is
"The power behind the beauty products". It is a **name list only**.

It does NOT contain, for any item:
- Descriptions
- Prices
- Pack sizes / variants / SKUs
- INCI lists, specifications, grades, CAS numbers
- Benefits or usage instructions (only a few group headings imply a function, e.g. "UV FILTERS")
- Stock or minimum order quantities
- Certifications

## 5. Missing information required before publishing anything

Per item: description, price (per kg / per pack), pack sizes, MOQ, stock, images, grade/INCI/CAS,
benefits and usage (only if the owner supplies them), certifications (COA/MSDS/etc.), GST/HSN rates.
